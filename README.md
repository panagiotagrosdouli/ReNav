# ReNav

Recoverability-aware navigation research for environments where executed actions can activate uncertain changes to future return connectivity.

## Research question

Can an executed-action history contain information about future safe-return connectivity that a planner using only the robot's current geometric state and fixed marginal hazard map cannot represent?

ReNav begins from the focused action-triggered topology-hazard work in DynNav. The code and retained summaries are research inputs, not ground truth. The current evidence is limited to constructed grid worlds and a frozen but not yet efficacy-validated Gazebo protocol. No physical-robot or general safety claim is made.

## Repository map

- `renav/`: reference grid model, return-connectivity oracle, planners, paired experiments, and statistics.
- `experiments/runners/`: deterministic command-line experiment entry points.
- `tests/`: known-answer and research-contract regressions.
- `ros2_ws/src/renav_nav2_cpp/`: Nav2 global-planner plugin.
- `ros2_ws/src/renav_nav2_benchmark/`: Gazebo/Nav2 execution protocol and runner.
- `docs/`: problem definition, research gap, literature matrix, protocols, limits, and reproducibility.
- `publication/`: inherited DynNav evidence ledger and manuscript references; inherited values are not ReNav results.
- `results/`: only outputs generated by ReNav runs, with run metadata and analysis.
- `data/`: dataset decision and manifests. No raw external dataset is currently required or bundled.

## Install and run

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev,plots]'
pytest
```

Run the frozen synthetic evaluations from the repository root:

```bash
python experiments/runners/run_history_information_gap_benchmark.py
python experiments/runners/run_heldout_history_generalization.py --seeds 500
python experiments/runners/run_geometric_heldout_benchmark.py --seeds 500
python experiments/runners/run_geometric_pareto_benchmark.py --seeds 500
python experiments/runners/run_joint_cut_counterexample.py
python experiments/runners/run_cut_scaling_benchmark.py
```

The runners preserve the source experiment semantics. Before treating any output as publication evidence, record the exact ReNav commit, command, parameters, seed set, Python/dependency versions, and raw-trial digest. See `docs/reproducibility.md`.

After the runs are present, rebuild the claim ledger, geometric summary table and paired-effect figure with `python scripts/build_evidence_manifest.py`.

## Model in brief

A hazard is a directed transition and a stochastic closure event elsewhere in the grid. The hazard becomes *active* only after that transition has been executed. Planning over candidate paths may reason about future activations but does not mutate persistent execution history. For position `x` and active hazard set `H`, the exact reference quantity is `P(a traversable path from x to the designated safe set | H)`, under the independent Bernoulli closure model.

The implementation compares geometric shortest path, fixed state-only marginal risk, exact history-conditioned A*, a critical-cut approximation, and a hard safe-return threshold. The hard constraint is a required comparator: existing constructed experiments show it can match the soft history objective.

## Evidence status

`publication/evidence_manifest_inherited_dynnav.json` records what the source repository reports and its upstream CI artifact identifiers. Those upstream raw artifacts were not included in the source checkout. ReNav has independently rerun the deterministic information-gap check, 500-seed heterogeneous/geometric paired evaluations, soft-vs-hard sweep, cut-approximation counterexample, and repeated cut-scaling timings. Raw trials and run manifests are under `results/reproduction/`; `publication/evidence_manifest.json` links claims to code, tests, trials, analysis and a generated geometric result table. These are reproductions of constructed synthetic studies, not new real-world evidence.

The central research gap is provisional. History-dependent robot risk, safe-return planning, belief-space planning, dynamic obstacle beliefs, and contingency feasibility all have substantial prior work. ReNav does not claim those topics are new. The candidate distinction—executed actions activating stochastic changes to *return connectivity*—needs broader literature review and stronger comparisons before any novelty claim is made.

## Current limits

The reference model assumes a known static grid, known directed triggers, known independent closure probabilities, and a designated safe set. It is not a belief-space or kinodynamic safety guarantee. The retained experiments use constructed worlds; they do not establish broad map generalization. The Gazebo scenario is frozen, but valid comparative execution outcomes have not yet been retained. No hardware experiment has been performed. The scaling result is a repeated within-host microbenchmark, not a cross-platform runtime claim. The local Python regression suite and ROS package tests still need to run in their respective CI environments.

See `docs/research_question.md`, `docs/research_gap.md`, `docs/experimental_protocol.md`, `docs/limitations.md`, `docs/self_review.md`, and `docs/audit_dynnav.md` before extending the method or reusing a result.
